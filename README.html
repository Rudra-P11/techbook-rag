02 Key Features

🔢
Zero-API-Cost Local Embeddings

Uses BAAI/bge-small-en-v1.5 via SentenceTransformers running locally on CPU. 33.3M params, 384 dimensions, 15–25 ms inference. No external API calls needed.

🗃️
Resilient Vector Store (Qdrant)

Connects to remote / Docker Qdrant if QDRANT_URL is set. Auto-fallback to embedded persistent storage at ./data/qdrant_storage when Docker is offline.

🔀
Hybrid Retrieval + RRF Fusion

Dense semantic search merged with BM25 Okapi lexical matching using Reciprocal Rank Fusion (k=60). Eliminates score normalization issues across disparate scoring scales.

📎
Verifiable Page-Level Citations

Every fact tagged with evidence IDs [E1], [E2] and transformed into human-readable citations: [Deep Learning from Scratch, p. 72].

🛡️
Security Guardrails

Prompt injection filtering, input length constraints, domain scope enforcement, and hallucinated citation tag stripping. Non-technical queries rejected in < 15ms.

⚡
Measured Latency Telemetry

Per-request telemetry tracking retrieval ms, generation ms, and total end-to-end time. Warm retrieval SLA tested at ~68 ms. Total: 1.2 – 2.8 seconds.

04 Quick Start

01 Prerequisites

Python 3.11 or 3.12 · Git · Node.js 18+ (for React frontend)

02 Setup Virtual Environment & Install Dependencies
python -m venv venv # On Windows: .\venv\Scripts\activate # On Linux/macOS: source venv/bin/activate pip install -r requirements.txt
03 Configure Environment Variables

Copy .env.example → .env and provide your OpenAI API key:

OPENAI_API_KEY=sk-proj-your-key-here OPENAI_MODEL=gpt-4o-mini
04 Ingest Books from the Corpus Directory
python scripts/ingest_directory.py --dir ./Corpus
05 Launch Application

Option A — React + Vite Frontend (Recommended)

# Terminal 1 — FastAPI REST server: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload # Terminal 2 — React Web App: cd frontend && npm run dev

Open http://localhost:3000 in your browser.

Option B — Streamlit Python UI

streamlit run app/ui/streamlit_app.py

Open http://localhost:8501 in your browser.

05 Testing & Evaluation

Test Suite Command
🧪 Unit Tests python -m pytest tests/unit -v
📊 Retrieval Benchmarks
Results → evaluation/reports/retrieval_report.json		 python scripts/evaluate_retrieval.py
